**Fråga:**
```
Vilka hygienstandarder måste vårt tvättsystem uppfylla?
```

**Svar:**
```
För vårdinrättningar i Sverige gäller primärt EN 14065 (hygienisk tvätteriprocess) och EN ISO 15883 (desinfektion). Dessa standarder säkerställer att tvättprocessen eliminerar patogener effektivt.

Utöver detta ska systemet klara Socialstyrelsens krav för vårdhygien och ofta även specifika kommunala eller regionala riktlinjer. Vi hjälper er att identifiera exakt vilka standarder som gäller för just er verksamhetstyp och säkerställer att systemet uppfyller dem.

Dokumentation och spårbarhet är också kritiskt vid inspektioner – något våra system har inbyggt.
```

### Fråga 2

**Projektfas:** Programskede

**Fråga:**
```
Hur dimensionerar vi rätt kapacitet för vårt äldreboende/sjukhus?
```

**Svar:**
```
Kapacitet beror på flera faktorer:
- Antal sängplatser/vårdplatser
- Vårdtyp (akutvård kräver mer än äldreboende)
- Omsättningshastighet (hur snabbt ska tvätt vara tillbaka?)
- Toppbelastning (influensasäsong, magsjukeutbrott)

Som tumregel räknar vi med 3-4 kg tvätt per sängplats och dygn för äldreboende, och 5-7 kg för akutsjukhus. Men det är viktigt att dimensionera för topp-scenario, inte snitt.

Använd gärna vår volymberäknare för att få en konkret rekommendation baserad på er verksamhet.
```

### Fråga 4

**Projektfas:** Projektering

**Fråga:**
```
Hur integrerar tvättsystemet med våra befintliga VVS- och ventilationssystem?
```

**Svar:**
```
Integration kräver samordning mellan flera system:

**VVS:** Tvättmaskiner behöver tillräckligt vattentryck (ofta 2-4 bar) och avlopp som klarar stora mängder vatten. Vi kontrollerar befintlig kapacitet och rekommenderar eventuella uppgraderingar.

**Ventilation:** Torktumlare genererar mycket fukt och värme. Ventilationssystemet måste klara 400-800 m³/h per torktumlare. Vi arbetar med er VVS-konsult för att säkerställa korrekt dimensionering.

**El:** Professionella maskiner kräver 3-fas 400V. Vi gör en elbehovsanalys och koordinerar med er elektriker.

Vår styrka är direktkontakt – vi tar helhetsansvaret för koordineringen så att du slipper springa mellan olika leverantörer.
```

**Schema markup-ready:** Ja
