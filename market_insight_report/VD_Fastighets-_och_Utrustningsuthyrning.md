# VD Fastighets- och Utrustningsuthyrning

# Rapport: Utmaningar vid upphandling av tvättlösningar/tvättrum
**Av: Erfaren VD för Fastighets- och Utrustningsuthyrning med fokus på
projektering och upphandling av tvättlösningar**


---


## 1. Persona & kontext (kort)


- **Typ av projekt:**
  Jag arbetar främst med flerbostadshus, studentbostäder och äldreboenden
där tvättrum ska integreras i fastigheten. Projekten kan vara nyproduktion
eller större ombyggnader där tvättsystem ska uppgraderas.


- **Min roll och ansvar:**
  Jag ansvarar för att projektera, välja och upphandla tvättlösningar som
optimerar funktion, ekonomi och drift. Jag säkerställer att lösningen möter
tekniska krav, användarnas behov och fastighetens långsiktiga underhåll.


- **Samverkansparter:**
  - Arkitekter (för integration i byggnadens layout)
  - Beställare (fastighetsägare eller förvaltare)
  - Driftsansvariga (för långsiktig service och underhåll)
  - Upphandlare (juridik och kontrakt)
  - Installatörer och leverantörer (teknisk implementation)

## 3. Faser & hur problemen ändras över tid


- **Tidigt skede (Program, Systemhandling):**
  Jag fokuserar främst på att definiera rätt kapacitet, tekniska funktioner
och miljökrav. Min oro gäller ofta hur väl utrustningen passar fastighetens
förutsättningar och framtida behov. Budget och livscykelkostnader är diffusa
men börjar ta form. Jag känner stor osäkerhet kring integration och
framtidssäkring.


- **Upphandling och installationsfas:**
  Här är min huvudvärk främst kring att säkerställa att leverantörer kan
leverera enligt tidplan, att installationen samordnas med övriga byggmoment
och att kvalitetskraven följs. Jag är också orolig för att kontraktsvillkor
håller vad de lovar och att serviceavtal är tydliga. Kommunikation och
samordning är kritiska.


- **Överlämning och driftsättning:**
  Min största rädsla är att överlämning och utbildning inte sker ordentligt,
vilket kan leda till driftstörningar och missnöje bland användare. Jag oroar
mig också för att garantier och serviceavtal inte följs upp noggrant, vilket
kan innebära kostsamma reparationer senare. Energi- och vattenuppföljning
börjar bli viktig för att hålla kostnader nere.

## 4. Vad jag önskar av en leverantör av tvättlösningar


1. **Tydliga och detaljerade livscykelkostnadsberäkningar (kopplat till ID
5, 26)**
      Jag vill att leverantören levererar transparenta LCC-analyser inklusive
investering, drift, underhåll och energi, så jag slipper gissa och kan fatta
välgrundade beslut. Det gör att jag känner mig trygg att ekonomin håller
under hela systemets livstid.


2. **Flexibla och modulära system med framtidssäkring (kopplat till ID 16,
22)**
      Jag vill kunna uppgradera eller byta ut delar utan omfattande ombyggnad,
vilket minskar risken för snabba föråldringar. Det ger mig trygghet i att
investeringen håller över tid.


3. **Integrationsmöjligheter med fastighetens system för bokning och
fjärrövervakning (kopplat till ID 14, 27, 30)**
      Jag vill att leverantören erbjuder lösningar som enkelt kan kopplas till
våra befintliga system, så att drift och användning blir effektiv och
kostnadseffektiv. Då känner jag mig säker på att systemet är modernt och
lätt att hantera.


4. **Enkel och användarvänlig maskin- och betalningslösning (kopplat till ID
9, 23)**
      Jag behöver att utrustningen är intuitiv så att användarna kan hantera
maskinerna utan problem, vilket minskar skador och klagomål. Det gör att jag
kan undvika onödiga driftstörningar.


5. **Tydliga och realistiska tidplaner med leveransgarantier (kopplat till
ID 7, 13, 21)**
      Jag vill att leverantören garanterar leverans och installation enligt
överenskommen tidplan, med tydliga konsekvenser vid förseningar. Det skapar
trygghet att projektet kan slutföras i tid.


6. **Komplett utbildningspaket för drift- och underhållspersonal (kopplat
till ID 18, 10)**
      Jag vill att leverantören ansvarar för att utbilda personal ordentligt,
så att vi undviker felaktig användning och driftproblem. Det ger mig
förtroende för att systemet fungerar smidigt i vardagen.


7. **Serviceavtal med tydliga garantier och uppföljning (kopplat till ID 6,
11, 25)**
      Jag vill ha tydliga avtal som inkluderar regelbunden uppföljning och
snabb respons vid problem, så att jag slipper oroa mig för kostsamma avbrott
senare. Det gör att jag känner mig trygg att systemet hålls i gott skick.


8. **Energieffektiva och miljövänliga lösningar med dokumenterad prestanda
(kopplat till ID 2, 12, 24)**
      Jag vill se bevis på att utrustningen verkligen sparar energi och är
miljöanpassad, så att projektet kan uppfylla hållbarhetsmål utan att riskera
efterhandskrav. Då känner jag att vi gör rätt för miljön och ekonomin.


9. **Support vid projektering och samordning med andra entreprenörer
(kopplat till ID 4, 15, 29)**
      Jag önskar att leverantören aktivt hjälper till att samordna installation
med övriga byggmoment och besvarar tekniska frågor snabbt, för att undvika
missförstånd och förseningar. Det skapar trygghet i hela byggprocessen.


10. **Ljudnivåanpassade maskiner och lösningar för att minimera störningar
(kopplat till ID 19)**
      Jag vill att leverantören erbjuder tystgående maskiner och dokumentation
kring ljudnivåer, så att boendemiljön inte påverkas negativt. Då slipper jag
klagomål och krav på åtgärder.


---
**Sammanfattning:**
Jag behöver en leverantör som inte bara levererar tvättmaskiner utan är en
partner i hela processen – från projektering, upphandling till långsiktig
drift. Tydlighet, flexibilitet, integration och support är nyckelord för att
jag ska känna mig trygg och kunna garantera en fungerande, kostnadseffektiv
och hållbar tvättlösning till våra fastigheter.
