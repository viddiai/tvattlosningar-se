# Projektfasguide: Programskede

## Rätt beslut från början – Programskedet är kritiskt

Programskedet är där grunden läggs för hela projektets framgång. Fel gjorda här multipliceras och blir dyra att rätta senare. Vi hjälper er fatta rätt beslut från start.

---

## Vad är programskedet?

**Definition:** Den tidiga planeringsfasen där ni definierar VAD ni behöver uppnå (inte HUR).

**Typiska frågor i denna fas:**
- Vad är våra faktiska behov?
- Vilken kapacitet krävs?
- Vilka krav och standarder gäller?
- Hur mycket bör vi budgetera?
- Vilka alternativ finns?

**Output från programskedet:**
- Behovsbeskrivning/programhandling
- Budgetram
- Övergripande kravspecifikation
- Beslut om projektering kan starta

---

## De 7 kritiska besluten i programskedet

### 1. Kapacitets- och dimensionering

**Fel som görs ofta:**
- Dimensionera baserat på kvadratmeter eller sängplatser (för trubbigt)
- Glömma toppbelastning (dimensionera för genomsnitt)
- Inte planera för framtida tillväxt
- Kopiera "liknande projekt" utan att validera

**Rätt approach:**
✓ Analysera faktiska användningsmönster
✓ Mät eller uppskatta textilvolymer (kg/dag, kg/vecka)
✓ Identifiera toppar (säsong, event, influensa, etc.)
✓ Planera 15-20% buffert för tillväxt
✓ Validera mot referensprojekt

**KENs stöd:**
- **Kapacitetsberäkningsverktyg:** Ange verksamhetsdata → få dimensioneringsrekommendation
- **Referensdata:** Jämför med liknande verksamheter
- **Scenarioanalys:** "Vad händer om vi växer 30% om 5 år?"

**Konkret exempel:**
- **FEL:** Äldreboende 80 platser → "Standard är 1 maskin per 40 platser" → 2 maskiner
- **RÄTT:** 80 platser × 8 kg lakan/vecka/plats = 640 kg/vecka → Toppbelastning vinter (+40%) = 896 kg/vecka → Behöver 2× 18 kg eller 3× 12 kg maskiner + flexibilitet

### 2. Centraliserad vs. decentraliserad lösning

**Centraliserad (en stor tvättstuga):**
✓ Fördelar:
- Lägre kostnad per maskin
- Enklare bemanning (koncentrerad)
- Professionell miljö (bättre zonsseparering)
- Enklare service och underhåll

✗ Nackdelar:
- Kräver transport av textilier
- Flaskhals om system går sönder
- Kan kräva dedikerat utrymme

**Decentraliserad (flera små tvättstugor):**
✓ Fördelar:
- Närhet till användare
- Flexibilitet (olika avdelningar/våningar)
- Mindre risk (ett system sönder ≠ totalstopp)

✗ Nackdelar:
- Högre total kostnad
- Svårare att upprätthålla standard
- Fler servicepunkter
- Svårare kontroll över hygien

**När ska ni välja vad?**

| Verksamhetstyp | Rekommendation | Motivering |
|----------------|----------------|------------|
| **Sjukhus/vård** | Centraliserad | Hygien kritiskt – behöver professionell zonsseparering |
| **Äldreboende (< 60 platser)** | Decentraliserad (2-3 mindre) | Närhet viktig, volymer låga |
| **Äldreboende (> 60 platser)** | Centraliserad | Volymer motiverar professionell lösning |
| **Flerbostadshus** | Decentraliserad | Boende vill ha närhet |
| **Hotell** | Centraliserad | Professionella volymer, personal hanterar |
| **Idrottsanläggning** | Centraliserad | Höga volymer, professionell hantering |

**KENs stöd:**
- Komparativ analys centraliserad vs. decentraliserad för ert specifika fall
- Total kostnadsjämförelse (10-års perspektiv)

### 3. Hygien- och säkerhetsstandarder

**Vanlig förvirring:** Vilka standarder gäller för oss?

**Rätt standarder per bransch:**

**Vård (sjukhus, äldreboenden):**
- EN 14065 (Tvättbehandling av textilier i processen för biologisk dekontaminering)
- ISO 15797 (Procedurmått för kommersiella tvätterier)
- AFS 2022:1 (Smittrisker - hygieniska gränsvärden)
- Patientlagen (spårbarhet)

**Räddningstjänst:**
- MSB:s rekommendationer för dekontaminering
- ISO 6330 (Textil vård)
- AFS 2001:1 (Systematiskt arbetsmiljöarbete)

**Sport/fritid:**
- Folkhälsomyndighetens allmänna råd
- Lokala hygien normer (kommun)
- Ev. certifieringskrav (ex. Svensk Simidrottsförbund)

**Bygg/fastighet:**
- BBR (Boverkets byggregler) - ventilation
- Miljöbyggnad/BREEAM (om certifiering eftersträvas)

**Djurvård:**
- Jordbruksverkets djurskyddsbestämmelser (L123)
- AFS 2005:1 (Smittrisker)
- Lokala tillståndsvillkor

**KENs stöd:**
- **Standardguide per bransch:** Vilka gäller för er specifika verksamhet
- Hjälp att tolka och oversätta till konkreta krav
- Kontakt med certifieringsorgan om ni är osäkra

### 4. Miljö- och hållbarhetsmål

**Vanligt misstag:** Besluta om miljökrav sent → dyra justeringar

**Beslut som bör fattas i programskedet:**

**Energieffektivitet:**
- Vilken energiklass krävs? (A+++ rekommenderat)
- Värmepump-integration? (återvinn 50-60% av energi)
- Solceller/grön el-integration?

**Vattenförbrukning:**
- Mål för liter/kg tvätt? (Bästa: <7 liter/kg)
- Gråvattenåtervinning? (tekniskt möjligt, sällan ekonomiskt)

**Kemikalier:**
- Miljömärkta kemikalier (Svanenmärkt, EU Ecolabel)?
- Minimera kemikalieförbrukning (automatisk dosering)?
- Biologiskt nedbrytbara medel?

**Certifiering:**
- Miljöbyggnad (Silver/Guld)?
- BREEAM?
- ISO 14001 (miljöledningssystem)?

**KENs stöd:**
- **Miljöprestanda-kalkylator:** Jämför olika system
- EPD (Environmental Product Declaration) för alla system
- Hjälp att uppfylla certifieringskrav

**Konkret exempel:**
Bostadsprojekt med Miljöbyggnad Gold-mål:
- Krav: Energi < 0,60 kWh/kg, vatten < 6 liter/kg
- KEN-lösning: Värmepumps-torktumlare + automatisk dosering → 0,52 kWh/kg + 5,8 liter/kg
- Resultat: 2 poäng bidrag till Miljöbyggnad Gold

### 5. Framtida flexibilitet och skalbarhet

**Frågor att ställa:**

**Tillväxt:**
- Vad händer om verksamheten växer 20-50%?
- Kan system skalas utan totalrenovering?

**Förändrade behov:**
- Vad om textiltyper förändras? (Ex. tyngre täcken, specialmaterial)
- Vad om hygienkrav skärps?

**Teknologiutveckling:**
- Kan system uppgraderas digitalt?
- Kan integration med framtida system ske?

**Rätt beslut i programskedet:**

✓ **Modulära lösningar:** Flera mindre maskiner vs. en stor (enklare att lägga till)
✓ **Överkapacitet i infrastruktur:** El/vatten/avlopp dimensionerat för +30% tillväxt
✓ **Standardiserade komponenter:** Inte proprietära system som låser er
✓ **Digital-ready:** System med API/integration möjligheter

**KENs approach:**
- Alla våra system modulära och skalbara
- Infrastruktur alltid dimensionerad för framtida expansion
- Knivity-plattform kontinuerligt uppdaterad (ingen "föråldrad teknik")

### 6. Budgetram och finansieringsmodell

**Vanligt problem:** Fokus bara på investeringskostnad (CapEx) → glömma driftskostnad (OpEx)

**Rätt budgetering i programskedet:**

**Total ägandekostnad (TCO) över 10-15 år:**
```
TCO = Initial investering
      + Installation och driftsättning
      + Årlig drift (el, vatten, kemikalier) × år
      + Service och underhåll × år
      + Reparationer och utbyten
      + Avveckling
```

**Exempel: Äldreboende, 2 maskiner + 2 torktumlare**

| Post | Kostnad |
|------|---------|
| Utrustning | 380 000 kr |
| Installation | 95 000 kr |
| Utbildning & driftsättning | 25 000 kr |
| **Initial (År 0)** | **500 000 kr** |
| El (3 500 kr/mån × 12 × 10 år) | 420 000 kr |
| Vatten (800 kr/mån × 12 × 10 år) | 96 000 kr |
| Kemikalier (1 200 kr/mån × 12 × 10 år) | 144 000 kr |
| Service (2 500 kr/mån × 12 × 10 år) | 300 000 kr |
| **Drift 10 år** | **960 000 kr** |
| **TCO 10 år** | **1 460 000 kr** |

**Per år:** 146 000 kr
**Per plats/år (60 platser):** 2 433 kr

**Alternativa finansieringsmodeller att överväga:**

**1. Traditionellt köp**
- Ni äger, ni ansvarar
- Passar: Organisationer med kapital och kompetens

**2. Lease/Hyra**
- Fast månadskostnad, inget ägande
- Passar: Begränsad CapEx-budget, vill ha förutsägbarhet

**3. Tjänstemodell (as-a-service)**
- Betala per kg tvätt
- Passar: Osäkra volymer, vill minimera risk

**4. Full service-avtal**
- Fast pris inkl. allt (utrustning, drift, service)
- Passar: Vill inte ha internt ansvar

**KENs stöd:**
- **TCO-kalkylator:** Transparent jämförelse alla alternativ
- Flexibla finansieringsmodeller anpassade er situation
- Hjälp att presentera för beslutsfattare (politiker, styrelse)

### 7. Utrymme och placering

**Kritiska beslut i programskedet:**

**Utrymmesbehov:**
- Hur mycket yta krävs? (inkl. service, logistik, förvaring)
- Takhöjd? (vissa torkskåp kräver 2,6-3,0 m)
- Dörröppningar för leverans? (maskiner ofta >700 mm bredd)

**Placering:**
- Var i byggnaden? (närhet till användare vs. störning)
- Koppling till vått-utrymmen? (enklare VVS-installation)
- Vibrations-/bullerpåverkan? (ej under sovrum/patientrum)
- Zonsseparering möjlig? (kritiskt för vård/räddningstjänst)

**Infrastruktur:**
- El-tillgång? (ofta 3-fas, 25-40A)
- Vatten/avlopp? (tryck, dimension, placering)
- Ventilation? (ofta 250-600 m³/h behövs)
- IT-uppkoppling? (Knivity kräver nätverk)

**Utrymmesrekommendationer:**

| Verksamhetstyp | Maskiner | Yta behov | Kommentar |
|----------------|----------|-----------|-----------|
| **Äldreboende (40-60 pl)** | 2+2 | 15-20 m² | Inkl. sortering & förvaring |
| **Sjukhus-avdelning** | 2+2 | 20-30 m² | Zonsseparering kräver mer |
| **Flerbostadshus (100 lgh)** | 4+4 | 25-35 m² | Gemensam tvättstuga |
| **Idrottsanläggning** | 2+2 | 18-25 m² | Sortering viktig (olika textilier) |
| **Räddningstjänst** | 1-2+skåp | 20-40 m² | Zonsseparering kritisk |

**KENs stöd:**
- **Utrymmesberäkningsverktyg:** Ange utrustning → få exakt yta
- 3D-layoutskisser (kan importeras i BIM)
- Platsbesök för bedömning av befintliga lokaler

- [ ] Finansieringsmodell vald (köp/lease/service)

## Vanliga misstag i programskedet – och hur undvika dem

### Misstag 1: Kopiera utan att anpassa

**Vad som händer:**
"Vi bygger likadant som projekt X" → Kopierar lösning utan att validera behov

**Konsekvens:**
- Över- eller underdimensionering
- Fel systemtyp för er verksamhet
- Kostnader högre än nödvändigt

**Rätt approach:**
- Använd referensprojekt som UTGÅNGSPUNKT, inte mall
- Validera era specifika behov
- Justera baserat på skillnader

### Misstag 2: Fokus på CapEx istället för TCO

**Vad som händer:**
"Billigaste i inköp vinner" → Glömmer driftskostnad

**Konsekvens:**
- Högre totalkostnad på 10 år
- Lägre kvalitet system
- Fler haverier och problem

**Rätt approach:**
- Alltid räkna TCO (10-15 år)
- Jämför långsiktigt, inte bara initialt
- Överväg lease om CapEx-budget begränsat

### Misstag 3: Glömma framtida flexibilitet

**Vad som händer:**
Dimensionerar exakt för dagens behov → Ingen marginal för tillväxt

**Konsekvens:**
- System för litet om 3-5 år
- Dyr uppgradering eller totalrenovering
- Flaskhalsar i verksamheten

**Rätt approach:**
- 15-20% buffert över prognostiserad volym
- Modulära system (enkelt lägga till)
- Infrastruktur dimensionerad för expansion

### Misstag 4: Sent involvera driftorganisation

**Vad som händer:**
Beslut fattas utan att fråga de som ska använda systemet

**Konsekvens:**
- System passar inte faktiskt arbetsflöde
- Användare missnöjda → dålig compliance
- Oväntade utbildningsbehov

**Rätt approach:**
- Involvera drift TIDIGT (redan programskede)
- Workshop med framtida användare
- Testa/besök liknande system innan beslut

### Misstag 5: Underskatta infrastrukturkostnad

**Vad som händer:**
Budgeterar endast utrustning → Glömmer el, vatten, ventilation, bygg

**Konsekvens:**
- Budgetöverskridande (ofta 30-50%)
- Förseningar när problem upptäcks i byggskede
- Kompromisser på lösning pga begränsad budget

**Rätt approach:**
- Infrastrukturanalys INNAN budgetbeslut
- Budgetera 40-60% av utrustningskostnad för installation/infrastruktur
- Platsbesök tidigt för bedömning

## Sammanfattning: Framgångsfaktorer i programskedet

✓ **Fokusera på BEHOV, inte lösningar** (VAD, inte HUR)
✓ **Räkna TCO, inte bara CapEx** (långsiktigt perspektiv)
✓ **Validera med data och referenser** (inte gissa)
✓ **Planera för framtiden** (flexibilitet och skalbarhet)
✓ **Involvera rätt personer tidigt** (drift, hygien, ekonomi)
✓ **Budgetera realistiskt** (utrustning + infrastruktur)
✓ **Ta hjälp av experter** (KEN-konsultation kostnadsfri)

**Programskedet väl genomfört = 80% av projektet framgång säkrad**
